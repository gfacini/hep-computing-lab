# HEP Computing Lab

Generate simulated LHC collisions, turn particle records into spectra, and reconstruct the mass of a Z candidate from two muons.

| Lesson | What you’ll make | Time |
|---|---|---:|
| [The Mac command line](notebooks/01-terminal.ipynb) | A small event-count file and a Python environment check | 30 min |
| [Generate proton–proton collisions](notebooks/02-pythia.ipynb) | 100 simulated events and a particle inventory | 35 min |
| [Plot particle spectra](notebooks/03-spectra.ipynb) | Transverse momentum, pseudorapidity and multiplicity histograms | 40 min |
| [Reconstruct a Z candidate](notebooks/04-z-dimuon.ipynb) | An opposite-sign dimuon mass spectrum | 45 min |

Start with [setup](setup.md). Each lesson has runnable examples and three challenges with hints. Bring a result, a short explanation and a check you ran. For the Codex challenge, predict the result before running suggested code and explain how you verified it.
